# Prototype assets

## Current UX reference

`Astana-City-Map-UX-prototype.pdf` is the six-page UX prototype supplied for this iteration. Its pages cover:

1. City map with hazard overlays, wind alert, parking markers and selected parking summary.
2. Parking list, occupancy states, camera freshness and occupancy history.
3. Hazard list with categories, severity and source/time metadata.
4. Citizen hazard-report form with category, location pin, description, optional photo and moderation notice.
5. Bottom navigation state.
6. Administrator moderation for hazard reports and events.

Rendered page images are under `pdf-pages/`. The interactive React implementation is under `../src/`.

## Earlier low-fidelity wireframes

The original five SVG wireframes and PNG exports are retained in `src/` and `png/`. They reflect an earlier broader planning scope and should not override the supplied six-page UX PDF for this iteration.
